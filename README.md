# UPSRTC Retro Music Player

A responsive, web-based music player featuring vintage retro aesthetics inspired by classic Uttar Pradesh State Road Transport Corporation (UPSRTC) buses. This project seamlessly blends nostalgic transit art with a modern, glassmorphism-styled audio interface for a unique listening experience across both desktop and mobile devices.
